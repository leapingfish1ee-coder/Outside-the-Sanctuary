# Outside the Sanctuary — BrandDesignGuideline

版本：2.0 · 2026-10-04
适用：游戏 HUD、Wiki、后续网页、原创图形与交互。
实现：`styles/brand.css`、`styles/hud.css`、`styles/wiki.css`。

## 1. 品牌命题

**圣所之外，是一份仍在发生的战场档案。**

早期互联网古典主义提供衬线字标、正文、链接、目录与表格的直接性；现代平面设计提供网格、留白、基线、编号和信息关系；拓扑抽象将技能压缩为圆、方与交叠关系；轻拟物仅通过边缘、槽位、刻度和按压状态表达操作与状态。

品牌气质：冷静、文学性、精确、朴素。白场是内容之间的距离，细线是关系边界，颜色是属性和战斗状态。页面应像排版严谨的档案页，同时具备即时响应的游戏仪表。

方法依据为仓库固定的 `emilkowalski/skills` 提交 `e8a175de22ae1e49370fc144c1f3bb9aeedf988d`，以及本地 `emil-design-eng` 技能：用一致的默认值、可预测反馈和边缘情形处理累积品质。以下参数是本项目的具体设计决策，不代表上游技能的原文要求。

## 2. 字标与语言

正式英文名称为 **Outside the Sanctuary**，中文名称为 **圣所之外**。主字标固定两行：第一行 `Outside the`，第二行 `Sanctuary`；保持完整名称，不附加装饰性徽章。

字标采用正常字重，字距 `-.035em`，行高 `1.08`。字标使用真实文字，允许选择、缩放和辅助技术读取。HUD 副标题为“圣所之外 · 自动战斗”；Wiki 副标题为“圣所之外 · 职业档案”。界面文案说明真实内容，不使用开发阶段说明。

`CHARACTER`、`WAVE` 与 `WIKI / 01` 是信息索引；编号只能标识章节、序列或状态。

| 角色 | 字体 | 字号 | 行高 / 字距 | 使用 |

| Wiki H1 | 宋体 | 46px；≤860px 为 38px | 1.2 / -.025em | 文档主题 |

| 职业、等级 | 宋体 | 18px / 400 | 1.4 | 身份次信息 |
| Wiki 职业名 | 宋体 | 18px / 700 | 1.4 | 组合表单元格 |
| Wiki 正文 | 宋体 | 16px | 1.9 | 连续阅读 |
| 敌人名 | 宋体 | 14px / 700 | 1.5 | 战斗实体 |
| 标签、操作、日志 | 黑体 / 无衬线 | 12px | 1.5；日志 1.65 | 功能说明 |
| 章节标签、组合说明 | 黑体 / 无衬线 | 11px | 1.5；标签字距 .12em | 信息索引 |

宋体栈：`"Songti SC", SimSun, "宋体", "Times New Roman", serif`。
黑体栈：`"PingFang SC", SimHei, "黑体", Arial, sans-serif`。
等宽栈：`"SFMono-Regular", Consolas, "Liberation Mono", monospace`。

不加载远程字体。平台字形差异由字体分工、比例、字距和结构约束。数字使用 `tabular-nums`；正文限制到 `44em`。中文不施加大字距，不以缩放整个区域模拟小屏排版。

角色名、职业名和属性值允许换行，数值不用省略号；血量与经验的标签和值允许在窄屏分行。默认节奏为 4px 单位：4、8、12、16、20、24、32、44、48，1px 用于边界。

## 4. 网格与信息拓扑

HUD 左轴为品牌、角色、属性；中轴为敌人和底部技能；右轴为 Wiki 和日志。左侧三个区域共享左边界，中央战场与字标分列。技能栏独占最后一行并居中，避免侵入属性或日志。

桌面列定义：`minmax(280px,360px) / minmax(286px,1fr) / minmax(200px,280px)`。中央伸缩列承担留白。敌人最大宽度 320px，日志最大宽度 280px。

外边距为 `clamp(32px,4.1667vw,96px)`，1920px 视口对应 80px；顶部 44px、底部 32px。列距为 `clamp(32px,4vw,80px)`，行距 24px。

| 范围 | 结构 | 参数 |
| --- | --- | --- |
| >1200px | 三轴分列 | 左列 280–360px，中央弹性，右列 200–280px |
| 761–1200px | 两列，战场与日志居右 | 左列 280–320px，列距 48px，顶部 32px |
| ≤760px | 单列阅读顺序 | 字标 → 角色 → 战场 → 属性 → 日志；技能固定底部 |
| 361–760px | 移动外边距 | 20px |
| ≤360px | 极窄外边距 | 16px |

纵向空间不足时允许整页滚动。移动底部预留 `112px + safe-area`，技能栏距离底部 `12px + safe-area`。技能栏可以横向滚动，不强制缩小所有槽位。

Wiki 桌面为目录 / 文档双列，目录宽 `clamp(240px,20vw,320px)`；≤860px 时目录进入文档流。表格最小宽度 900px，仅表格区域横向滚动；列头与首列分别吸附于区域顶端与左端。滚动区有名称、键盘焦点和提示。

## 5. 色彩与线条

| Token | 值 | 职责 |
| --- | --- | --- |
| `--paper` | #FFFFFF | 页面底色 |
| `--ink` | #111111 | 主文字、结构主线 |
| `--secondary` | #666666 | 次信息、操作文案 |
| `--muted` | #777777 | 时间、标签、组合关系 |
| `--rule` | #D7D7D7 | 次分隔、空槽边框 |
| `--hairline` | #EDEDED | 日志行线、极浅实体边缘 |
| `--surface` | #FAFAFA | 纯系职业、未装备槽 |

六属性：力量 #D64B4B、敏捷 #33C47A、智力 #5C6BFF、意志 #3FC7D6、灵知 #D8A03A、信仰 #C8D2D2。仅用于属性文字、图例和装备符号局部。属性文字从语义色收束到主黑，浅色不能独立承担整段文字对比。

生命填充为暗红 #8E3434 到主黑，经验为主黑；获得/失败日志分别为 #806229 与 #A33D36，状态同时有文字。主结构线、表格线与图标线均为 1px。结构圆角为 0，圆形只用于技能几何。

## 6. 轻拟物与拓扑抽象

轻拟物的边界是“可辨认的实体边缘”。

| 对象 | 实体感 | 信息职责 |
| --- | --- | --- |
| Wiki 入口 | 1px 黑框、2px 浅灰底边 | 可进入的档案入口 |
| 属性按钮 | 1px 次框、按下变灰、极轻 inset | 可分配面额 |
| 血条 | 6px 高线框轨道 | 当前量 / 总量 |
| 技能栏 | 1px 托盘框、2px 浅灰底边 | 已装备与空槽 |
| 技能符号 | 1px 圆、方、交叠 | 自动技能的视觉索引 |
| Wiki 表格 | 细网格、纯系极浅底色 | 主 / 副属性的有序关系 |

技能槽桌面 52×52px，间距 6px，内距 6px；窄屏 44×52px。仅装备槽呈现图形，空槽保留序号。冷却遮罩直接反映状态，不增加补间；图形不能替代技能名和数值。

不引入纸张噪点、皮革/石材/金属纹理、玻璃、大范围渐变、霓虹、徽章堆叠或商业游戏素材。拓扑来自区域、槽位和表格的关系，不额外添加无功能网络图。

## 7. 交互与运动

操作和状态更新频率高，默认即时反馈。属性按钮立即变色并提供轻 inset；Wiki 入口按下直接反色，不移动排版。不添加重复缩放、弹簧或出场动画。

交互焦点为 2px 主黑轮廓、4px 偏移。属性按钮最小宽度 44px，桌面最小高度 36px，窄屏最小高度 44px；多面额换到下一行。显示规则仍取决于实际可用点数。

hover 仅在 `(hover:hover) and (pointer:fine)` 生效，不能作为唯一反馈。此版没有位移动画，缩减动态模式无需另一套视觉行为；未来动画必须通过频率、用途与 reduced-motion 检查。

技能栏表达自动施放状态，不伪装成手动操作按钮。正文可选择，按钮文字不参与长按选择，页面允许缩放。

## 8. 设计审查

| Before | After | Why |
| --- | --- | --- |
| 单行字标与敌人区域可能相撞 | 双行字标、独立网格 | 保留品牌比例与战场可读性 |
| 属性区域整体缩放 | 实际字号、流式网格 | 字形与操作尺寸稳定 |
| 面额按钮绝对坐标摆放 | 单面额行内、多面额换行 | 窄屏与大数值仍可操作 |
| 技能栏与日志共占底部 | 技能独立一行，窄屏固定 | 解除重叠 |
| 空技能槽也有复杂图案 | 空槽简化 | 图形表达装备状态 |
| 日志 8–10px 且隐藏溢出 | 正文 12px、时间 10px、局部滚动 | 可读且可访问历史 |
| Wiki 缺少冻结轴与滚动语义 | 聚焦区、行列头、吸附轴 | 保持主副属性参照 |
| 字体与灰阶散落 | 共享 token | 跨页面细节一致 |

## 9. 实施与交付

新增页面先使用 `styles/brand.css`，再定义页面布局。此文档是现行参数来源；原 Graphic Design Guideline 的黑白、宋体、细线、语义色、原创资产原则继续有效。保留静态 HTML/CSS/JavaScript 发布结构。

交付检查：1920×1080、1366×768、1100px 附近、760px、320px；200% 缩放的视口重排；长身份名、敌人名、大数值、多面额和零数据；键盘焦点、表格滚动、既有自动战斗测试；对应提交 GitHub Pages 部署成功。

线上只发布 `index.html`、`wiki.html`、`game.js` 和 `styles/`；工具、测试与规范留在 Git 仓库。
